# AtomicTracker - Habit Tracking App

A React-based habit tracking application inspired by Atomic Habits by James Clear.

## Features

- **Landing Page** - Authentication and onboarding
- **Dashboard** - Main habit tracking interface with heatmaps
- **Identity Management** - Define your identity and beliefs
- **Performance Tracker** - Analytics and historical data
- **Weekly Review** - Reflect on your progress

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Build

```bash
npm run build
```

## Tech Stack

- React 18
- React Router v6
- Tailwind CSS
- Vite
